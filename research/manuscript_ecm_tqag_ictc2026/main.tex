\begin{abstract}
ECM-TQAG is an evidence-first protocol for constructing traceable multimodal textbook question-answering items. It compares direct, answer-first, and evidence-chain generation from frozen text--structure--image packages. In the evidence-chain method, a planner proposes a source-bound document graph and requests a motif from a closed catalog. Deterministic code validates and matches the motif, compiles it into a restricted program, executes that program, and derives answer atoms with node, edge, and program-step provenance. A separate realizer receives only this locked construction---not the original text or image pixels---and constructs one four-option question. We release a reproducible runner, audit, tests, and a reporting design that separates executable structural/provenance validity from semantic correctness, pedagogical quality, and genuine visual necessity.
\end{abstract}
\begin{IEEEkeywords}
multimodal question generation, textbook question answering, evidence-grounded generation, provenance-aware generation, document understanding

\section{Introduction}
Textbooks distribute instructional content across prose, headings, tables, diagrams, charts, and page layout. A multimodal textbook question-answering (TQA) item must retain an inspectable relation among its answer and supporting evidence; attaching an image alone does not make an item visually grounded. Document models combine text, geometry, and visual representations \cite{xu2020layoutlm,xu2021layoutlmv2,huang2022layoutlmv3}; document, table, and chart QA demonstrate the role of structured and visual evidence \cite{mathew2021docvqa,herzig2020tapas,tito2023multipage,kafle2018dvqa,masry2022chartqa}; and question generation supports visual and educational authoring \cite{mostafazadeh2016generating,zhu2016visual7w,heilman2010good,kurdi2020systematic}. Yet a generation pipeline for source documents must preserve answer provenance before writing a question and assess whether visual pixels are actually needed.

This work addresses traceable multimodal TQA construction from textbook evidence. ECM-TQAG adopts an evidence-first, answer-before-question sequence:
\begin{equation}
G_m \rightarrow z \rightarrow (A,\Gamma) \rightarrow q \rightarrow \mathcal{C},
\end{equation}
where a matched motif $G_m$ supplies a restricted program $z$, yielding typed answer atoms $A$ and a provenance trace $\Gamma$ before a four-option question $q$ is checked by $\mathcal{C}$. Crucially, $G_m$, $z$, $A$, and $\Gamma$ are computed by deterministic local code rather than emitted by the language model. The approach combines compositional reasoning over scenes, diagrams, and structured visual evidence \cite{johnson2017clevr,hudson2019gqa,kafle2018dvqa,masry2022chartqa} with provenance models that distinguish source records from derived artifacts \cite{moreau2013prov}.

The contributions are: (i) a source-grounded representation with matched evidence packages and image-integrity receipts; (ii) motif-guided, answer-before-question derivation of atoms and traces, in which motif matching, program compilation, execution, and tracing are executable rather than declarative; and (iii) a replayable contract for package identity, derivation, atom--trace correspondence, and MCQ consistency. ECM-TQAG is a construction protocol, not a document encoder or an answering model.

\section{ECM-TQAG Construction Protocol}
\subsection{Document representation and evidence packages}
A source document is $D=(T,L,V,M,\Pi)$: text, structure/layout, visual regions, metadata, and source-level provenance. Parsing and alignment produce
\begin{equation}
G=(N,E,\rho),\qquad N=N_T\cup N_L\cup N_V\cup N_M,
\end{equation}
where $\rho:N\rightarrow\Pi$ links each node to a descriptor such as source digest, page, region, and extraction metadata. This source mapping is distinct from the item-level trace $\Gamma$ \cite{moreau2013prov}. In the implementation, $\rho$ is recomputed deterministically from the frozen package: a text node carries the package text digest and its character span, a structure node carries the declared section title and header level, and a visual node carries the declared image order, image digest, byte size, and source page.

For each selected chunk, let $c\in K=\{\T,\TL,\TLV\}$ denote an evidence-condition label. ECM-TQAG forms the paired evidence packages
\begin{equation}
\mathcal{X}_{\T}=(T),\quad \mathcal{X}_{\TL}=(T,L),\quad \mathcal{X}_{\TLV}=(T,L,V).
\end{equation}
Packages retain chunk identity while exposing text, then structure, then original image pixels; records retain $c$, source references, and image integrity information verified before each request.

\subsection{Evidence-first item construction}
A motif template defines a typed pattern and derivation template. A matched $G_m\subseteq G$ supplies the restricted program $z$; unresolved inputs or incomplete provenance terminate construction. The language model proposes only the typed graph and a motif request: evidence-node IDs encode modality ($\mathtt{T}i$, $\mathtt{S}i$, $\mathtt{I}i$) with roles \emph{premise}, \emph{mapping}, or \emph{constraint}, and directed edges reach a single derived claim node through the finite relations \emph{supports}, \emph{maps-to}, and \emph{constrains}. A deterministic matcher then evaluates the request against a versioned catalog that fixes the required role set, one incoming edge per bound node, and the role--relation correspondence; a model-supplied motif label alone is insufficient.

A compiler maps the successful match to a closed opcode sequence over typed values, $\mathtt{select\_nodes}$, $\mathtt{traverse\_to\_claim}$, $\mathtt{read\_value}$, and $\mathtt{return\_atoms}$, with exactly-one-target cardinality. Execution yields an answer structure and a trace:
\begin{equation}
A=\mathrm{Exec}(z,G_m),\qquad \Gamma=\mathrm{Trace}(z,G_m).
\end{equation}
Here $A=(a_1,\dots,a_k)$ contains answer atoms and $\Gamma=(\gamma_1,\dots,\gamma_k)$ links each $a_j$ to its source nodes or regions via $\rho$. The retained item contains the motif, derivation, answer parts, traces, MCQ, answer index, and rationale; a SHA-256 receipt seals $G$, $\rho$, $G_m$, $z$, $A$, and $\Gamma$. Because the model cannot emit $z$, $A$, or $\Gamma$, answer content is a function of the graph rather than of free generation. A second, isolated realizer receives only the sealed construction, not the package or image pixels, and must preserve atom identifiers, values, and step trace, anchor every bound node exactly, and select the executor-derived atom. This content-before-realization ordering follows educational QG practice \cite{kurdi2020systematic}; the contract requires answer--choice agreement and one trace per atom. For ECM--$\TLV$ the matched motif must bind a visual node, which constrains construction but does not prove counterfactual visual necessity for a human respondent \cite{goyal2017making,agrawal2018don}.

\subsection{Construction checks}
The final check set $\mathcal{C}$ enforces package identity, well-formed derivation, non-empty atoms, atom--trace correspondence, four distinct options, and answer--choice agreement. Replay is exact rather than schematic: the audit recomputes $\rho$, re-matches the motif, recompiles $z$, re-executes $A$, retraces $\Gamma$, and recomputes the receipt, so a tampered program, atom, trace, provenance descriptor, or anchor is rejected. The same library serves the runner online and the audit offline. It complements MCQ item-writing criteria \cite{haladyna2002review}, and SHA-256 receipts bind package and output records for reproducibility and audit \cite{sandve2013ten,raji2020closing}; they do not establish that a model-proposed edge or claim is semantically valid, nor legal correctness, unique-best-answer validity, distractor quality, difficulty, or image-grounding truth.

\subsection{Direct and answer-first baselines}
\emph{Direct} requests one four-option MCQ from a directly supported proposition. \emph{Answer-first} requires a declared answer and evidence excerpt before the question and same-domain distractors; a deterministic check requires the declared answer to equal the selected option. Both retain source-labelled evidence anchors, but neither derives atoms from a matched motif. Thus chunk and available evidence are fixed while the construction protocol changes.

\section{Experiment and Reporting Design}
\label{sec:experiments}
The executable matrix contains eight selected chunks from five Vietnamese law textbooks, three evidence conditions, and three protocols: $8\times3\times3=72$ output cells. Direct and Answer-first make one request per cell. ECM makes a planner call and, only after a valid plan, a realization call; a complete run therefore plans 96 API calls. Results are written to a new, non-overwriting JSONL ledger with raw provider responses, prompt hashes, input-field receipts, plan/realizer provenance, and status records for parsed, rejected, and transport-error cells.

The manuscript presents the graph--motif--restricted-program protocol and reporting boundary. It intentionally does not reuse numerical results from earlier single-call, evidence-plan, or historical ledgers, because their contracts differ from the executable construction described above. Numerical results are reported only from the completed matrix and its corresponding deterministic replay audit.

A post-generation quality gate has two levels. First, the mechanical audit checks record shape, distinct options, answer/choice agreement where applicable, source-bound graph nodes, typed edges, motif predicates, exact compiler output, executor-derived atoms, construction receipts, program traces, locked anchors, and the ECM--$\TLV$ image-node requirement. Second, independent human or expert review must assess semantic correctness, one-best-answer validity, evidence sufficiency, distractor quality, pedagogical usefulness, and whether image pixels are genuinely needed. Automated parsing or contract validity is not a substitute for this review.

\subsection{ECM matrix result and rejection taxonomy}
The completed exploratory matrix contains 72 cells. After replacing two demonstrably under-contextualized packages and rerunning only their 18 affected cells, 60 cells (83.3\%) were parsed and 12 (16.7\%) were rejected. The original evidence version contributed 54 unaffected cells (47 parsed, 7 rejected); the augmented version contributed 18 rerun cells (13 parsed, 5 rejected). Audits were performed separately against the two manifest digests and then combined by provenance partition, avoiding a false provenance failure caused by auditing records from different evidence versions against one manifest.

The 12 rejections fall into four operational scenarios: (i) five insufficient-evidence decisions (four on the title/image-only \textit{LUAT CHUNG KHOAN} package and one on a long but difficult legal-text package), where the model or planner declined to construct an item under the evidence contract; (ii) four literal-grounding failures, in which a text graph node or anchor paraphrased rather than reproduced a contiguous source span (three on the legal-text chunk and one on the augmented French-court diagram package); (iii) two ECM answer-binding failures, where the selected option could not be bound to the executor atom; and (iv) one invalid ECM anchor on the legal-text package. The first scenario is an evidence-coverage limitation, while the latter three are model output/contract failures. The short title/image-only package was augmented only where a semantically adjacent OCR context existed; unrelated neighbouring material was not injected. These figures measure structural parsing and provenance validity only, not legal correctness, one-best-answer validity, pedagogy, or visual necessity.

\section{Limitations}
The selected corpus establishes a reproducible feasibility setting, not generalization across document genres. The graph is model-proposed: literal source binding and executable traversal do not prove that an edge relation or derived claim is semantically or legally correct. The current contract also does not prove that distractors are educationally appropriate or that an image is counterfactually necessary. Those claims require documented expert review and learner-oriented studies \cite{kurdi2020systematic,haladyna2002review}. The image-node requirement cannot replace explicit visual-dependence evaluation \cite{goyal2017making,agrawal2018don}.

\section{Conclusion}
ECM-TQAG provides an executable evidence-first protocol for multimodal textbook MCQ construction. Its planner proposes a source-bound document graph; local code matches a closed-catalog motif, compiles and executes a restricted program, and derives provenance-bearing answer atoms; and its isolated realizer receives only that sealed construction. The method makes structural construction replayable while keeping stronger claims about graph semantics, legal correctness, pedagogy, and visual necessity contingent on completed expert evaluation.
