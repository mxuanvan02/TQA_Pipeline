# Ethics and Release Policy

## Release target

- Public release (full dataset + scripts + documentation), subject to license checks.

## Minimum release package

- Dataset files (or approved subset if legal limits apply)
- Data card
- Provenance table
- Reproduction scripts and config snapshots
- Evaluation protocol and limitations

## Safety and risk controls

1. Legal misuse risk
- State that outputs are educational/research data, not legal advice.

2. Hallucination risk
- Keep judge-filter and human-audit traces.

3. Privacy and sensitive content
- Remove or mask personal identifiers if discovered.

4. Licensing compliance
- No source content should be redistributed without verified rights.

## Responsible use statement

- For research and educational use.
- Any legal decision-making deployment requires additional expert validation.
